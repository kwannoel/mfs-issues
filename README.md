# MFs issue tracker

This public repository tracks bugs and feature requests for MFs. The application source code is maintained separately in a private repository.

- [Report a bug](https://github.com/kwannoel/mfs-issues/issues/new?template=bug-report.md&labels=bug)
- [Request a feature](https://github.com/kwannoel/mfs-issues/issues/new?template=feature-request.md&labels=enhancement)
- [Browse existing issues](https://github.com/kwannoel/mfs-issues/issues)

## Privacy

Everything submitted here is public. Do not include API keys, credentials, private repository links, or personal fitness records such as actual weights, meals, or sleep times. Use synthetic example values when they are necessary to explain a bug.

The MFs agent can prepare a prefilled issue link. Nothing is published until you review the draft on GitHub and select **Submit new issue**.
